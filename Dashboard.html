Data Loading Info
  • Data
  • Preprocessing

Metabolomics experiments leverage multiple data tables for analysis. The datasets needed for the downstream analysis are:

1.) Sample metadata

  • Must contain a column with sample names (e.g. PARENT_SAMPLE_NAME) corresponding to the sample names in the peak data.

2.) Chemical annotation

  • Must contain a column with chemical IDs (e.g. CHEM_ID) corresponding to the chemical IDs in the peak data.

3.) Peak data (samples x metabolites).

The MetabolomicsPipline contains tools for processing the peak data to prepare it for downstream analysis. The following preprocessing steps are used:

  • Median standardization
  • Minimum value imputation
  • Log transformation

If you are using your own data, you can choose to use the MetabolomicsPipelines preprocessing or upload your own normalized data. If you choose to upload your own normalized data, it must be in the same format as the peak data (samples x metabolites).
